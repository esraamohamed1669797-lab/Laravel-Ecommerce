# Laravel Ecommerce

A complete E-commerce Web Application built with Laravel.

## Features

- Authentication System
- Admin Dashboard
- Product Management
- Categories & Subcategories
- Brands Management
- Shopping Cart
- Wishlist
- Coupons System
- Order Management
- Responsive Design

## Technologies

- Laravel
- PHP
- MySQL
- Bootstrap
- JavaScript
- jQuery
- HTML
- CSS

## Installation

```bash
git clone https://github.com/esraamohamed1669797-lab/Laravel-Ecommerce.git

cd Laravel-Ecommerce

composer install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan serve
```
