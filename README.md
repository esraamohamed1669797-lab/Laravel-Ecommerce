# 🛒 Laravel E-Commerce Website

A complete E-Commerce web application built with **Laravel**, featuring a modern user interface, secure authentication, admin dashboard, shopping cart, wishlist, coupon system, and order management.

---

# 📌 Project Overview
This project is a complete Laravel-based E-Commerce website that provides customers with a smooth online shopping experience and gives administrators full control over products, categories, brands, orders, coupons, users, and homepage content through an integrated admin dashboard.

# ⚙️ Installation

```bash
git clone https://github.com/esraamohamed1669797-lab/Laravel-Ecommerce.git

cd Laravel-Ecommerce

composer install

npm install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan db:seed

php artisan storage:link

npm run dev

php artisan serve
```

---
